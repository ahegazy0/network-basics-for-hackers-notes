## What's inside each module

- Plain English explanations of every concept
- All key commands with real examples
- Quick reference tables
- ASCII diagrams where they actually help
- Practice labs and exercises at the end

---

## Requirements

- [VirtualBox](https://www.virtualbox.org/) or any VM software
- [Kali Linux](https://www.kali.org/get-kali/) (64-bit)
- For Wi-Fi modules: external wireless adapter with monitor mode support is needed.

## Disclaimer

This course notes is for educational purposes only. Everything here should be practiced in your own lab environment. Never test on systems you don't own or have explicit permission to test.
