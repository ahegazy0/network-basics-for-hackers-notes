# Network Basics for Hackers - Notes

A structured set of networking study notes based on the book *Network Basics for Hackers* by OccupyTheWeb. Originally compiled during personal lab practice in Obsidian, then structured and organized with AI assistance for clarity, consistency, and easy navigation.

> **Update:** Visual architecture diagrams have been added across core protocol modules to illustrate concepts like the TCP handshake, ARP poisoning, DNS resolution, and CAN bus networks.
